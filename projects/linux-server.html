System Administration & Security Environment: Ubuntu 22.04 LTS / Debian 12

Linux Server Hardening & Enterprise Administration

End-to-end deployment, secure configuration, and proactive monitoring of production Linux server instances. Built following CIS Benchmarks for OS hardening, zero-trust network access, and automated service management.

Access Control ED25519 Keys + PAM MFA
Network Defense UFW + Fail2ban Integration
Web Stack Nginx Reverse Proxy + SSL
Monitoring Systemd + Journald Logging

Executive Overview & Objectives

Default Linux server installations often ship with open ports, permissive authentication options, and unmonitored baseline services. This project outlines the systematic transformation of a stock Linux distribution into a hardened, production-grade server capable of hosting sensitive web applications while resisting automated brute-force attacks and unauthorized access attempts.

  • Eliminate single-point password vulnerability by enforcing key-based SSH authentication.
  • Implement a least-privilege network entry strategy using Uncomplicated Firewall (UFW).
  • Deploy automated intrusion prevention mechanics to detect and jail malicious traffic.
  • Configure Nginx as a reverse proxy with TLS 1.3 encryption and security headers.

Technical Implementation & Security Controls

1. SSH Daemon Hardening (sshd_config)

Disabled password authentication completely in favor of 4096-bit RSA or ED25519 keypairs. Re-routed standard SSH ports, blocked direct root logins, and configured strict session timeouts.

# /etc/ssh/sshd_config security baseline PermitRootLogin no PasswordAuthentication no PubkeyAuthentication yes MaxAuthTries 3 ClientAliveInterval 300 ClientAliveCountMax 2 X11Forwarding no

2. Perimeter Control & Intrusion Prevention (UFW + Fail2ban)

Enforced a strict "default-deny" incoming policy. Allowed only explicit inbound ports (HTTP/HTTPS and custom management ports) and paired UFW with Fail2ban to monitor log files for brute-force signatures.

# UFW Firewall Setup sudo ufw default deny incoming sudo ufw default allow outgoing sudo ufw allow 80/tcp sudo ufw allow 443/tcp sudo ufw allow 22/tcp sudo ufw enable

3. Web Service Proxying & SSL/TLS Hardening

Configured Nginx as a hardened reverse proxy with Let's Encrypt TLS certificates. Enforced HTTP Strict Transport Security (HSTS), X-Frame-Options, and disabled legacy SSLv3/TLS 1.0/1.1 protocols.

System Monitoring & Log Auditing

To maintain operational awareness, system health indicators and security events are aggregated and monitored:

Journald & Logrotate

Centralized log filtering with structured queries using journalctl and automated log compression/rotation policies to prevent disk space exhaustion.

Automated Security Updates

Configured unattended-upgrades to automatically apply critical Linux security patches without administrative delay.

Verification & Security Outcomes

  • Achieved A+ SSL Rating on SSL Labs evaluation.
  • Successfully blocked 100% of unauthenticated brute-force attempts via SSH during testing phase.
  • Maintained 99.9% uptime for self-hosted web services with automated service recovery scripts via systemd.
